# Abyss

## Browser Action RPG

Version: 0.1
Status: Planning
Repository: https://github.com/kyhsa93/game

## 프로젝트 목표
브라우저에서 실행되는 싱글 플레이 핵앤슬래시 RPG를 개발한다.

- 전투
- 성장
- 파밍
- 빌드 연구

초기 버전은 서버 없이 LocalStorage 기반으로 동작한다.

- 캐릭터 이동

- 아이템 드랍
