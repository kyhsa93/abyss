# DUNGEON SYSTEM

## Core Concept

Infinite procedural dungeon progression.

## Room Types

- Start Room
- Combat Room
- Treasure Room
- Elite Room
- Boss Room

## Floor Structure

Town
↓
Start
↓
Combat
↓
Combat
↓
Elite
↓
Boss

## Scaling

Every Floor:

- Monster HP +8%
- Monster Damage +5%
- Experience +6%
- Gold +5%

## Elite Monsters

Chance: 10%

Modifiers:
- Fast
- Strong
- Armored

## Boss Monsters

One boss per floor.

Guaranteed reward.

## Endgame

No maximum floor.

Players compete against their own progression and build strength.
