# ITEM SYSTEM

## Philosophy

아이템은 Abyss의 핵심 성장 수단이다.

Final Item = Base Item + Rarity + Affixes

## Item Rarity

- Normal
- Magic
- Rare
- Set
- Unique

## Prefixes

- Strong (+Attack)
- Sharp (+Critical Chance)
- Swift (+Attack Speed)
- Sturdy (+Defense)

## Suffixes

- of Power
- of Fury
- of Protection
- of Vitality

## Affix Count

- Normal: 0
- Magic: 1-2
- Rare: 3-6
- Set: Fixed
- Unique: Fixed

## Unique Items

Unique items have handcrafted stats and unique effects.

## Set Items

Set items grant bonuses when multiple pieces are equipped.

2 Pieces: Minor Bonus
3 Pieces: Major Bonus
Full Set: Unique Effect

## Item Level

Item Level (ilvl) equals monster level.

Higher ilvl unlocks stronger affixes.

## Drop Philosophy

Players should always have a chance to find a meaningful upgrade.
